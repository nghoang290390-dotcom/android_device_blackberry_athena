# LineageOS 24.0 – BlackBerry KEY2 (athena)

**Android 17 | Unofficial Build**

LineageOS 24.0 for BlackBerry KEY2, developed by **Hoang**, based on the original LineageOS 23.2 source from **FumoEnterprises**.

### Improvements & Features
- Android 17 bring-up and boot fixes.
- Hardware compatibility and camera HAL fixes.
- Physical keyboard and touchpad improvements.
- BoomSound dual-speaker mode.
- CPU Boost and custom Quick Settings toggles.
- GitHub-based OTA updates.
